# Technique knowledge (optional)

Techniques are **mechanisms**, not doctrine. They load **only after** a [decision](../decision/) domain identifies a credible candidate (e.g. compute-bound + data parallelism → [simd.md](simd.md)).

- The catalog is **intentionally incomplete**.
- A listed technique is **not evidence** it fits your workload.
- Missing technique → **KNOWLEDGE GAP** + authoritative research; optional hub promotion later (see [docs/engineering-doctrine.md](../../../docs/engineering-doctrine.md)).

Do not bulk-load this directory for performance-sensitive tasks.
